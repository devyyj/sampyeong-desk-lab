# SDL 모바일 중심 UI/UX 전면 개편 설계

- 작성일: 2026-10-16
- 브랜치: `feature/mobile-redesign` (develop 기준)

## 1. 목적과 범위

회원들은 휴대폰으로 **피드 구경·반응**, **활동 기록·사진 보기**, **글·사진 올리기**를 주로 한다.
현재 화면은 데스크톱 웹 레이아웃을 줄여 놓은 형태라 메뉴가 햄버거 안에 숨고, 피드 사진은 작은 썸네일이며,
보드게임 카테고리 칩 30여 개가 첫 화면을 덮고, 활동 제목이 잘린다.

- **범위**: UI + 화면 구성(내비게이션, 카드, 시트, 레이아웃) 변경.
- **유지**: 서버 액션, DB 조회, 권한 정책(비회원 읽기 전용, 실명·부서·활동 사진은 회원 전용), 이미지 업로드 흐름.
- **범위 밖**: 피드 무한 스크롤, 활동 목록 사진 썸네일, 다크 모드 수동 전환, PWA.

## 2. 결정 사항

| 항목 | 결정 |
|---|---|
| 톤 | 네이티브 앱 같은 미니멀, 모노크롬(검정 포인트) |
| 폰트 | Pretendard Variable (next/font/local, 셀프 호스팅) |
| 내비게이션 | 하단 5탭: 피드 · 활동 · 보드게임 · 회원 · MY. 글쓰기 FAB는 피드에서만 |
| 피드 | 인스타형: 풀폭 4:5 사진 캐러셀(scroll-snap), 본문 3줄 접기, 댓글 바텀시트 |
| 활동 | 두 줄 리스트(제목 / 배지·날짜·사진 수·반응) + 시즌 헤더 sticky |
| 보드게임 | 검색 + 칩 3개(전체·공용 보관함·카테고리▾) + 카테고리 바텀시트, 행 탭 → 상세 시트(수정·삭제) |
| 데스크톱 | lg 이상에서 탭바 → 왼쪽 사이드 레일, 본문 중앙 컬럼 |

## 3. 앱 셸

- `TopBar`: 48px. 화면 제목 + 우측 액션. 상세 화면은 `‹` 뒤로가기.
- `TabBar`: 하단 고정, `safe-area-inset-bottom` 반영, 현재 탭 `aria-current="page"`. 하위 경로도 상위 탭을 활성으로 본다.
  글쓰기·수정 화면(`/posts/write`, `/posts/*/edit`)에서는 숨긴다.
- `Fab`: 피드(`/`)에서만. 비회원이면 `/login?redirect=%2Fposts%2Fwrite`.
- `GNB`·햄버거 메뉴 제거. 관리자·로그아웃·동호회 안내는 MY로 이동.

## 4. 화면

- **피드 `/`**: 작성자 줄(아바타·닉네임·배지·상대 시간·본인 글이면 `···` 시트: 수정/삭제) → `PhotoCarousel` → 좋아요·댓글 버튼 → 본문 → 댓글 N개 보기(바텀시트에 `CommentSection`).
- **글쓰기/수정**: 전체 화면, 상단 `취소 | 제목 | 올리기`, 사진 가로 스트립 → 본문. 업로드 로직 유지.
- **활동 `/activities`**: 두 줄 리스트, sticky 시즌 헤더(TopBar 아래). **상세**: 회원은 사진 캐러셀, 비회원은 "로그인하면 사진 N장" 안내.
- **보드게임 `/boardgames`**: 칩 3개 + 카테고리 시트(개수 많은 순, 미분류 마지막). 필터는 URL 쿼리 유지.
  행 탭 → 상세 시트(회원은 수정·삭제). 보유자 실명은 회원에게만 클라이언트로 전달. 등록은 TopBar `＋`(회원).
- **회원 `/members`**: 시즌 가로 칩, 리스트 행, 비회원은 로그인 안내.
- **MY `/my` (신규, 공개)**: 회원은 프로필 헤더 + 메뉴(프로필 편집 `/mypage`, 동호회 안내, 관리자, 로그아웃). 비회원은 로그인 버튼 + 동호회 안내.
- 기타(`/mypage`, `/login`, `/change-pin`, `/admin/members`, `/about/*`): TopBar + 폼 스타일 정리.

## 5. 디자인 토큰

배경 `#fff` / 글자 `#0a0a0a` / 보조 `#737373` / 구분선 `#ececec` / 포인트 = 글자색.
예외 색: 좋아요 빨강, 활동 종류 배지. 다크 모드는 `prefers-color-scheme` 유지.
카드 테두리·그림자 최소화, 구분선·여백으로 영역 구분. 터치 타깃 최소 44px.

## 6. 접근성

탭 `aria-current`, 바텀시트 `role="dialog"`·`aria-modal`·포커스 트랩·Esc/배경 닫기·포커스 복귀,
캐러셀 키보드 이동과 "사진 n/N" 라벨, `prefers-reduced-motion` 존중.

## 7. 테스트

- Vitest(TDD): `TabBar`, `Fab`, `BottomSheet`, `PhotoCarousel`, `/my`, route-guard(`/my` 공개). 기존 페이지 테스트는 새 마크업에 맞게 수정하되 권한 검증은 유지.
- Playwright: `mobile`(iPhone 13) 프로젝트 추가, 헤드리스. 탭 이동, 사진 첨부 글쓰기, 댓글 시트, 보드게임 카테고리 시트, MY 로그아웃, 비회원 FAB → 로그인.
- 단계마다 `npx tsc --noEmit`, `npm run build`, 모바일·데스크톱 스크린샷 확인.

## 8. 단계

1. 토큰·폰트·앱 셸(`TopBar`·`TabBar`·`Fab`·사이드 레일)·`/my`, GNB 제거

3. 피드 + 글쓰기
4. 활동
5. 보드게임
6. 회원·MY·기타 화면
